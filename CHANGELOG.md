# Changelog

All notable changes to PlantHelper are recorded here. Versions follow `ApplicationDisplayVersion` in `src/PlantHelper/PlantHelper.csproj`.

## 1.0.0

First release.

### Plants
- Plant list with search, filter and sort.
- Add and edit form, detail page, growth stage and status (active, harvested, archived, lost).

### Care journal
- Ten entry types: water, feed, measure, environment, pest, training, transplant, harvest, stage change and note.
- Nutrient library with label doses.
- One-tap *Mark done* for watering and feeding.
- Optional daily care reminder.

### Photos
- Camera capture and system photo picker.
- Photo details, full-screen viewer, before/after compare and gallery.
- Stored copies have location data removed.

### Dashboard and charts
- Home dashboard with stats, today's care, upcoming care, grower tips and recent activity.
- Growth charts and growth-rate figures per plant.

### Grower tools
- VPD, daily light integral (DLI), PPM ↔ EC, nutrient mixer and unit converter.

### Data
- Backup export and import (`.zip`) with merge or replace; imports are validated and staged before anything on the device changes.
- Journal export as CSV.
- Delete all data from Settings.

### Settings
- Metric or imperial units, °C or °F, EC or PPM 500/640/700.
- Light, dark or system theme.

### Privacy and Play compliance
- All data stays on the device; no internet permission, no account, no analytics.
- Android cloud backup disabled for app data.
- Windowed daily alarm, so no exact-alarm permission is needed.
- In-app privacy policy.
